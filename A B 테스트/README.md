# 마케팅 캠페인 A/B 테스트 분석

광고(ad)와 공익광고(psa)를 본 사용자의 구매 전환율을 비교해, **광고 캠페인을 계속 운영할지** 판단한 분석입니다. 「[통계적 검정과 인과추론] 종합 과제 안내 - A/B 테스트」 제출물입니다.

## 주요 결과

- 광고 그룹의 전환율이 공익광고 그룹보다 높았습니다 (2.55% vs 1.79%).
- **+0.77%p** [95% CI +0.60, +0.94] · **1.43배** [95% CI 1.30, 1.58]
- χ²(1) = 54.32, p < .001, Cramér's V = 0.010
- 사용자 10,000명당 약 **77명** 추가 구매 (95% CI 60 ~ 94명)
- **결정: 출시** (광고 캠페인 계속 운영) — 단, 사용자 1명당 광고비가 `전환 1건의 가치 × 0.006` 미만이라는 손익분기 조건을 확인해야 합니다.

## 노트북 구성

| 단계 | 내용 |
| --- | --- |
| 1. 데이터 점검 | 행·컬럼·결측치, `Unnamed: 0` 제거, 중복, 배정 일관성, SRM(96:4), 세그먼트별 배정 비율, 노출량 균형 |
| 2. 질문과 가설 | 분석 목적 → 분석 질문 → 검정 질문, $H_0$ / $H_1$, α = 0.05 양측, 사전 결정 변수 고정 |
| 3. 검정 고르기 | 비율·2집단 → 카이제곱 독립성 검정(연속성 보정 없음), 기대 빈도 593.7명 ≥ 5 확인, 선택 근거 한 문단 |
| 4. 검정과 3종 세트 | 점추정 +0.77%p, 95% CI [+0.60, +0.94]%p, Cramér's V 0.010, 상대 차이 1.43배 |
| 5. 한 걸음 더 (C) | 요일 7 + 시간대 24 = 31개 세그먼트 피셔 정확 검정 → Bonferroni·BH 보정(13 → 9 → 4개), 라벨 순열 시뮬레이션 100회 |
| 6. 의사결정 | 출시 + 손익분기 조건, 가정과 한계 |
| 7. 종합 결론 | 한 페이지 요약 |
